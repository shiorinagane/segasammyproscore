# プロ個人戦 最終結果 LIFF（スプレッドシート駆動型）

セガサミー チャリティープロアマ大会「プロ個人戦」の最終結果をLINE内（LIFF）で表示する仕組み。
`score_ranking`（チーム戦・速報あり）と同じ仕組みだが、こちらは**最終結果のみ**を想定し、成立ホールの表示はない。

## 構成ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 結果表示ページ（GitHub Pagesに置く） |
| `gas_code.gs` | スプレッドシートを読むAPI（GASウェブアプリ） |
| `個人戦_最終結果.csv` | スプレッドシートにインポートする雛形（サンプルデータ入り） |
| `img/` | ロゴ・1〜3位バッジ画像（score_rankingと共通素材） |

## シートのレイアウト（固定位置）

| | A | B |
|---|---|---|
| 1 | 公開 | OK（空欄以外なら何でもよい） |
| 2 | 見出し | プロ個人戦 最終結果 |
| 3 | 説明文 | 本日のプロ個人戦、最終結果をお届けします。 |
| 4 | 更新時刻 | 7/23 17:00 |
| 5 | 表示数 | 空欄なら全員表示。数値を入れるとそこまでに絞れる（例：10） |
| 6 | 順位 | 選手名 | スコア（6行目はヘッダー） |
| 7〜 | データ本体 | | |

### ルール

- **B1（公開フラグ）**：空欄でなければ何でもON扱い。空欄に戻すとOFF（「準備中です」表示に戻る）
- **順位（A列）**：同点が起こり得るため、毎回手入力する運用にする（空欄なら上から自動連番）。同点は同じ順位、次の順位はタイの人数分スキップ（例：2位が2人同点なら両方`2`、次は`4`）
- **選手名（B列）**：空欄の行で読み込み終了。上位から順に入力する
- **スコア（C列）**：`-18`（アンダーパー）や`+3`など。`+`付き文字列でも数値でもOK（全角の−も自動変換）
- **1〜3位は同点なら全員分カード表示**：たとえば2位が2人同点なら、2位カードが2枚並ぶ（score_rankingと同じ仕様）
- **成立ホールはなし**：最終結果のみを想定しているため、この構成には含まれない

## 初回セットアップ（1回だけ）

### 1. スプレッドシート

1. 新規スプレッドシートを作成（例：「セガサミープロアマ_プロ個人戦」）
2. `個人戦_最終結果.csv` をシートとしてインポート（見出し・説明文・サンプル選手名は仮テキストなので、当日の実際の値に差し替える）
3. B1に「OK」など空欄以外の何かを入力すると公開状態になる（入力途中の状態では公開しないこと）
4. URLの `/d/〇〇〇/` 部分（スプレッドシートID）を控える

### 2. GAS

1. スプレッドシートのメニュー「拡張機能 → Apps Script」を開く
2. `gas_code.gs` の中身を貼り付け、`SPREADSHEET_ID` を手順1のIDに書き換える
3. 「デプロイ → 新しいデプロイ → ウェブアプリ」
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. 発行された `https://script.google.com/macros/s/…/exec` のURLを控える

コード修正時は「デプロイを管理 → 編集 → 新バージョン」で更新するとURLが変わらない。

### 3. GitHub Pages に index.html を置く

1. `index.html` 冒頭の `GAS_URL` を手順2のURLに書き換える（`LIFF_ID` は手順4で確定するので仮のままでよい。`SITE_URL` に大会公式サイトURLを入れるとフッターにリンクが出る）
2. GitHubにリポジトリを作成（public。`img/` の画像以外に個人情報は出ないので問題なし）

```bash
cd pro_final_ranking   # index.htmlのあるフォルダ
git init
git add index.html img
git commit -m "add pro final ranking page"
git branch -M main
git remote add origin https://github.com/<アカウント名>/<リポジトリ名>.git
git push -u origin main
```

3. GitHubのリポジトリ画面 → Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://<アカウント名>.github.io/<リポジトリ名>/` で公開される

### 4. LINE Developers で LIFF アプリを作成

score_rankingと同じプロバイダー内に、別のLIFFアプリとして追加する（別プロバイダーには作らない）。

1. score_rankingを作成した既存チャネル、または新規チャネルの「LIFF」タブ → 追加
   - LIFFアプリ名：プロ個人戦 最終結果
   - サイズ：**Full**
   - エンドポイントURL：手順3のGitHub Pages URL
   - Scope：`profile`
2. 発行された LIFF ID を `index.html` の `LIFF_ID` に反映して再push
3. チャネルのステータスが「公開済み」になっていることを確認（score_ranking側ですでに公開済みならそのまま使える）

## 当日の運用

1. プロ個人戦の最終結果が確定したら、スプレッドシートのA〜C列に順位・選手名・スコアを入力
2. B4の更新時刻を書き換える
3. 入力が終わったら **B1に「OK」など何か入力して公開状態にする**
4. LINE公式アカウントから配信文＋LIFF URLを配信

## 動作確認のチェックリスト

- [ ] ブラウザでGitHub Pages URLを開くと結果が表示される
- [ ] LINEアプリでLIFF URLを開くと結果が表示される
- [ ] B1を空欄にすると「結果は準備中です」と表示される
- [ ] 2位が同点のとき、2位カードが同点人数分並ぶ
- [ ] スコアのマイナス（アンダーパー）が緑、プラスが赤で表示される
